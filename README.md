# aGo Media

WordPress image optimization on upload (WebP, auto-resize, EXIF strip) and media auditing (missing ALT, orphaned, duplicates). **Free, no Pro tier.**

[English](#english) · [Español](#espanol)

---

## English

aGo Media optimizes images as they are uploaded: WebP conversion, sane maximum dimension, EXIF stripping. Also audits existing media for missing ALT text, orphaned attachments and near-duplicates.

### Features

- Auto WebP conversion for PNG and JPEG uploads.
- Resize oversized originals.
- Strip EXIF metadata.
- Audit missing ALT text, orphaned attachments and duplicates.
- Bulk optimize existing attachments.
- No external services.
